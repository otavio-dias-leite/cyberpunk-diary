# Cyberpunk Diary 1.2.1

Agenda pessoal offline-first para Windows, Android e navegador.

## Atualizações 1.2.1
- Menu lateral abre com gesto de arrastar da borda esquerda para a direita e fecha arrastando para a esquerda.
- Botão de menu e área escurecida também abrem/fecham o menu.
- Android: barra de status do sistema deixa de sobrepor o cabeçalho; cor e estilo configurados para combinar com a interface.
- Ajustes de área segura para telas com recorte e navegação por gestos.

## Funcionalidades
- Visões Agora, Dia, Semana e Mês.
- Tarefas, recorrências, tags, hábitos e notas Markdown.
- Temas, backup/importação, armazenamento local e sincronização P2P opcional.

## Compilação
Node.js 20+, Java 21 e Android SDK.
