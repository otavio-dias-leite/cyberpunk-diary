# Cyberpunk Diary 8.4 — Links funcionais

- Clique em links de descrições de tarefas, hábitos e notas para abrir em nova aba.
- Funciona também no editor visual e com Enter em links focados.
- URLs digitadas ou coladas são convertidas em links ao finalizar a palavra.
- Se o navegador bloquear a nova aba, o link abre na aba atual.
- Preserva dados, Markdown, checkboxes e salvamento automático.

Para publicar, substitua todos os arquivos e recarregue a página.
